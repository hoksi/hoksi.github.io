이번 실험은 [지난 실험](/ai/worm-predator/)의 의문에서 시작됐어요. 인위적으로 정해 준 규칙과 감각 연결이 오히려 꼬마선충에게 방해가 된 건 아닐까?
이번 글은 그중 감각 연결부터 확인해 본 이야기입니다.

꼬마선충을 Super Tank에 처음 연결할 때 가장 큰 고민 중 하나는 게임 진행 상황을 꼬마선충에게 어떻게 전달할까였습니다.

꼬마선충은 화면을 볼 수 없습니다. 실제로도 눈이 없구요.
게임에는 적 탱크(포식자), 적 탱크가 쏜 포탄(포식자의 공격), 초록 지뢰와 빨간 마름모(먹이)가 존재합니다.
이걸 어떻게 꼬마선충에게 알려 줘야 할까?
이를 위한 해결책으로 감각을 담당하는 뉴런(위험을 느끼거나 냄새를 맡는)에 게임 정보를 하나씩 연결하는 거였습니다.

모든 걸 제가 고르진 않았어요. 적절해 보이는 뉴런 후보는 AI가 생물학 자료를 보고 추천해 줬습니다.

- 적 탱크 → ASH (해로운 것을 피하게 하는 감각 뉴런)
- 먹이 → AWA (끌리는 냄새를 맡는 뉴런)
- 몸에 맞은 포탄 → 몸의 촉각 뉴런

게임 내에서 꼬마선충의 움직임은 연결된 감각에 따라 켜지는 운동 뉴런이 정합니다. 앞으로 기어갈 때 쓰는 뉴런(AVB)이 뒤로 물러날 때 쓰는 뉴런(AVA)보다 더 켜지면 탱크가 앞으로 가고, 반대면 뒤로 갑니다. 왼쪽, 오른쪽은 머리를 등쪽과 배쪽으로 구부리는 뉴런 중 어느 쪽이 더 켜졌는지로 정하고요. 대포는 먹은 걸 뱉어 내는 인두 뉴런이 켜지면 쏘는데, 이때는 정면에 적이 있을 때만 쏘도록 규칙을 하나 걸어 뒀습니다.
생물학 지식이 풍부한 꼬마선충 전문가는 아니어서 추천받은 연결이 맞는지 검증할 수가 없었지만 이렇게 연결해 놓으니 게임에서 움직이긴 하더라구요.

그런데 이런 연결 자체를 꼬마선충이 학습을 통하여 스스로 정하게 하는 게 더 좋지 않을까 하는 생각이 들었습니다.
인위적으로 연결을 만들어 준 꼬마선충을 '지정 연결'로, 학습을 통하여 스스로 연결을 정한 꼬마선충은 '자율 연결'이라 정의하였습니다.

두 꼬마선충의 차이는 이렇습니다.

| | 지정 연결 | 자율 연결 |
| --- | --- | --- |
| 게임 → 감각 | 사람이 정함 (적 → ASH) | 게임 정보 13가지를 어느 감각 뉴런에 넣을지 학습 과정에서 습득 |
| 운동 → 버튼 | 사람이 정함 (AVA → 후진) | 운동 뉴런 65개를 어떻게 읽을지 학습 과정에서 습득 |

둘 다 학습하지 않은 뇌 지도를 가지고 포식자가 있는 놀이터에서 500세대씩 학습하도록 했습니다.
이렇게 실험하여 선택된 연결을 확인해 보면 검증할 수 없던 AI의 추천을 꼬마선충을 통해 확인 가능할 것 같았습니다.

500세대씩 학습한 뒤 각각의 꼬마선충을 놀이터에서 12번씩 테스트하여 평균을 내봤습니다.

| | 지정 연결 | 자율 연결 |
| --- | --- | --- |
| 점수 | 2,317 | 2,546 |
| 버틴 걸음 (최대 1,500) | 657 | 1,208 |
| 잡힌 횟수 (목숨 3개) | 3.0 | 1.4 |
| 적을 쫓아낸 횟수 | 2.1 | 0 |

놀이터의 결과는 자율 연결의 승리였습니다. 이기는 방식도 달랐습니다. 지정 연결 꼬마선충은 공격적으로 적과 싸우며 먹이를 먹었고, 자율 연결 꼬마선충은 한 번도 쏘지 않고 적을 피하면서 먹이에 집중하였습니다.

자율 연결 꼬마선충이 학습을 통해 고른 연결을 확인해 봤습니다. 지정 연결은 감각 하나를 뉴런 한두 종류에만 넣었는데, 자율 연결은 대부분의 감각을 수십 개 뉴런에 조금씩 나눠 넣었습니다. '앞에 포식자' 신호는 코끝 촉각 뉴런(OLQ)과 산소를 느끼는 뉴런(BAG) 쪽으로 연결되었습니다. 위험을 감지하는 ASH로 연결될 거라는 추측을 벗어난 거죠.

생물학에 기반한 AI의 추천 중 맞아떨어진 것도 있었습니다. '앞으로 가기'는 몸통의 B형 운동 뉴런(VB, DB)에서 읽었고, '배쪽 몸 촉각'은 AVM, PVM 촉각 뉴런에 넣었습니다. 둘 다 지정 연결과 같은 선택이었죠.

놀이터 결과를 보고 자율 연결에 많은 기대를 걸고, 실제 게임에서 12번씩 테스트하여 평균을 냈습니다.

| | 놀이터 | 실제 게임 |
| --- | --- | --- |
| 지정 연결 | 2,317 | 2,321 |
| 자율 연결 | 2,546 | 1,867 |

기대와 달리 자율 연결이 지정 연결보다 성적이 좋지 않았습니다.

프로그래밍하는 것처럼 인위적으로 감각을 연결하는 것이 학습을 통해 스스로 선택한 연결보다 더 나은 건가 하는 생각이 들었습니다.
그러다 어쩌면 지정 연결 꼬마선충이 운이 좋은 걸지도 모른다는 생각이 들었어요.
지정 연결을 처음부터 시작하여 500세대 동안 한 번 더 학습시켜서 실제 게임에 투입했습니다.
두 번째 지정 연결 꼬마선충은 실제 게임에서 1,875점을 받았습니다. 자율 연결(1,867점)과 거의 같았어요.
게임 12판으로는 450점 정도의 오차가 생긴다는 것도 확인할 수 있었습니다.

감각 연결은 어느 쪽이 나은지 알 수 없게 되었네요. 좀 더 긴 시간 테스트하던가 학습을 시켜봐야 결론을 낼 것 같습니다.
이번 테스트 결과에서 한 가지 의문이 생겼습니다. 자율 연결한 꼬마선충은 왜 포식자를 한 번도 공격하지 않았을까?
